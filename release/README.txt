Spider Crawler
==============

A literal web crawler: drop a document, watch a spider read it, get the gist.

Start it
--------
  macOS     double-click start.command
            (the first time macOS may say it can't check the developer:
             right-click start.command, choose Open, then Open again)
  Windows   double-click start.bat
  Linux     ./start.command

Your browser opens on http://localhost:4321. Close the terminal window to stop.

It needs Node.js 22 or newer (https://nodejs.org). No other install, no internet
needed except to crawl links.

No Node? The dist/ folder is a plain static website: serve it with any web
server, or use the online version at https://lulu38m.github.io/spider-crawler/

More: https://github.com/lulu38m/spider-crawler
